
# 📊 Sales Performance Dashboard

## Project Overview

This project is an interactive Power BI dashboard created to analyze
sales performance and generate meaningful business insights.

The dashboard provides a clear overview of sales, profit, quantity,
orders, regions, categories and sub-categories.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
- Data Analysis

## 📈 Key Performance Indicators

| KPI | Value |
|---|---:|
| Total Sales | 1.57M |
| Total Profit | 175.26K |
| Total Quantity | 22K |
| Total Orders | 3K |

## 📊 Dashboard Analysis

The dashboard includes:

- Quarterly Sales Comparison
- Sales by Region
- Category-wise Sales Distribution
- Profit by Sub-Category
- Profit by Category
- Overall Sales Overview
